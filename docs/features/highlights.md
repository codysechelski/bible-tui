# Highlights

Press `c` to highlight the current verse, or every verse in a selection. Pick one of six colors with `1`–`6`
(or arrows and Enter), or clear the highlight with `0`.

![Highlighting verses in different colors](../../.tapes/highlight/gifs/feature-highlight-with-keys_small.gif)

> [!NOTE]
> GIF compression makes the colors in the animation look off. The screenshots below show the real highlight
> colors.

| | |
| --- | --- |
| ![The highlight color picker](../../.tapes/highlight/screenshots/showing-highlight-options.png) | ![A highlighted verse](../../.tapes/highlight/screenshots/showing-highlighted-verse.png) |
| The color picker | A highlighted verse |

`C` (or `"`) lists every highlight with its color, newest first. Enter jumps to one, and `d` or Delete removes
it.

![The highlights list](../../.tapes/highlight/screenshots/showing-highlights-list.png)

Like [marks](marks.md), highlights are saved (to `highlights.json`) and show in every version.
